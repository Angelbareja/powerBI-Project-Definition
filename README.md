# 📊 Superstore Sales & Profit Analysis Dashboard | Power BI

An interactive **Power BI Dashboard** designed to analyze Superstore sales performance, profitability, product quantities, and discount patterns.

## 🖥️ Dashboard Preview

![Superstore Dashboard](images/dashboard.png)

## 📌 Project Overview

This project focuses on analyzing Superstore sales data using Microsoft Power BI. The dashboard provides meaningful insights into sales, profit, quantity, and discount performance through interactive visualizations and filters.

The main purpose of this project is to understand business performance, identify trends, and support data-driven decision-making.

## 🎯 Project Objectives

- Analyze overall sales and profit performance.
- Monitor total quantity sold.
- Understand discount distribution.
- Compare performance across different product categories.
- Analyze sales and profit across four regions.
- Create an interactive and user-friendly dashboard.

## 🛠️ Tools & Technologies

| Tool | Purpose |
|---|---|
| Power BI Desktop | Dashboard creation and visualization |
| Power Query | Data cleaning and transformation |
| DAX | Calculations and KPI measures |
| CSV Dataset | Data source |

## 📂 Dataset Description

**Dataset Name:** Sample - Superstore.csv

The dataset contains information about customer orders, products, sales, profits, discounts, and geographical regions.

Important columns include:

- Order Date
- Ship Date
- Customer Name
- Segment
- Region
- State
- City
- Category
- Sub-Category
- Product Name
- Sales
- Quantity
- Discount
- Profit

## 📈 Dashboard Features

### 1. Key Performance Indicators (KPIs)

The dashboard includes four important KPIs:

| KPI | Description |
|---|---|
| Total Sales | Overall sales generated |
| Total Profit | Overall profit or loss |
| Total Quantity | Total products sold |
| Average Discount | Average discount provided |

### 2. Category Filter

The dashboard provides three interactive category filters:

- Furniture
- Office Supplies
- Technology

### 3. Region Filter

Users can filter the dashboard according to four regions:

- Central
- East
- South
- West

### 4. Sales Distribution Analysis

The sales distribution chart helps understand the distribution of records across different sales values.

### 5. Profit Distribution Analysis

The profit distribution chart helps analyze profitable and loss-making records.

## 🚀 How to Use This Project

1. Download or clone this repository.
2. Open Microsoft Power BI Desktop.
3. Import the Sample - Superstore.csv dataset.
4. Perform data preparation using Power Query.
5. Create the required KPI measures using DAX.
6. Design visualizations and interactive slicers.
7. Save and open the Power BI report.
